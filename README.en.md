# Brazukol Compiler

A Compilers coursework project featuring a small IDE for Brazukol, an educational language adapted from Portugol. It exposes token generation and selected syntactic and semantic checks.

**Java 8 · Swing · JFlex · Maven**

[Português](README.md) · [Computer Science portfolio](https://github.com/Danilo-Js/My-Computer-Science-Course)
